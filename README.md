# 🎮 Simon Game

A simple and interactive **Simon Game** built using **HTML, CSS, and JavaScript**. The game tests your memory by generating an increasingly long sequence of colours that you must repeat correctly.

---

## 📌 Features

- 🎯 Random colour sequence generation
- 📈 Level-based gameplay
- ✨ Button flash animations
- 🖱️ Mouse click interaction
- ⌨️ Press any key to start the game
- 💥 Game Over animation
- 🏆 Highest Score tracking
- 📱 Simple and responsive UI

---

## 🛠️ Technologies Used

- CSS3
- JavaScript (DOM Manipulation)

## 🚀 How to Play

1. Open the game in your browser.
2. Press **any key** to start.
3. Watch the colour that flashes.
4. Click the same coloured button.
5. At each new level, one more colour is added to the sequence.
6. Repeat the entire sequence correctly.
7. The game ends when you click the wrong colour.
8. Try to beat your **highest score**!

---

## 🎮 Game Rules

- Memorize the flashing sequence.
- Repeat the sequence in the same order.
- Every correct level increases the sequence by one colour.
- One wrong click ends the game.
- Press any key to restart after Game Over.

---

## 🧠 Game Logic

1. User presses any key.
2. Game starts from Level 1.
3. A random button flashes.
4. User repeats the sequence.
5. If correct:
   - Level increases.
   - Another random colour is added.
6. If incorrect:
   - Game Over message appears.
   - Highest score is updated.
   - Game resets.
